# cninfo-pdf-direct

解决网站有时候重定向而不使用浏览器内置 PDF 阅读器，提高编辑性。
加入了自动更新的功能来解决项目的下载和同步。
修复了国内网络不好同步的问题。

## 本地自选股

脚本会在 `www.cninfo.com.cn` 页面右上角显示“我的自选股”面板，可以：

- 添加股票代码和名称；
- 按代码或名称筛选；
- 删除自选股；
- 收起面板。
- 拖动标题栏调整面板位置，并自动记住位置。

自选股使用 Tampermonkey 的本地存储保存，不需要登录巨潮资讯，也不会上传到服务器。清理浏览器或 Tampermonkey 的站点数据可能会删除这些内容。
